# Cactus Server

HTTPS-сервер для M5Stick-кактуса. Принимает показания датчиков, хранит историю, позволяет управлять подсветкой и насосом через браузер.

## Требования

- Python 3.9+
- pip

## Установка

```bash
pip install -r requirements.txt
```

## Запуск на локальном ПК

### 1. Узнай свой IP

**Windows:**
```
ipconfig
```
Ищи строку `IPv4-адрес` в нужном сетевом адаптере (Wi-Fi или Ethernet).  
Пример: `192.168.1.100`

**Linux / macOS:**
```
ip a
```

### 2. Запусти сервер

```bash
python server.py
```

При первом запуске автоматически создаются `cert.pem` и `key.pem` (самоподписанный сертификат, срок 10 лет).

В консоли появится напоминание о нужном `SERVER_URL`:

```
========================================================
  HTTPS server: https://0.0.0.0:8443
  Dashboard:    https://localhost:8443/

  Прожги в M5Stick config.h:
    #define SERVER_URL "https://<IP>:8443/api/cactus"
  Узнать свой IP:  ipconfig  (Windows) / ip a  (Linux)
========================================================
```

### 3. Настрой M5Stick

В файле `software_m5stick/include/config.h` пропиши IP своего ПК:

```c
#define SERVER_URL "https://192.168.1.100:8443/api/cactus"
```

Перепрошей устройство. M5Stick начнёт отправлять данные каждые 60 секунд (по умолчанию).

### 4. Открой дашборд

Перейди в браузере на:

```
https://localhost:8443/
```

Браузер покажет предупреждение о самоподписанном сертификате — нажми «Подробнее» → «Всё равно перейти». Это нормально: M5Stick проверку сертификата пропускает.

## Дашборд

На главной странице отображается:

- **Последние показания** — влажность, состояние подсветки и насоса, время получения
- **Команды** — кнопки для управления светом и насосом

Команда ставится в очередь и уходит на устройство в ответе на следующий запрос M5Stick (раз в `SERVER_POLL_S` секунд, по умолчанию 60).

Страница автоматически обновляется каждые 30 секунд.

## API

### `POST /api/cactus`

Основной эндпоинт, который вызывает M5Stick.

**Тело запроса:**
```json
{"humidity": 45, "light": true, "pump": false, "ts": 1748123456}
```

**Ответ** — JSON с командами (поля присутствуют только если есть что выполнить):
```json
{"cmd_light": "on", "cmd_pump": "off"}
```

---

### `POST /api/command`

Поставить команду в очередь. Вызывается дашбордом (или вручную).

```bash
curl -k -X POST https://localhost:8443/api/command \
     -H "Content-Type: application/json" \
     -d '{"cmd_light": "on"}'
```

Допустимые значения: `"on"`, `"off"`.

---

### `GET /api/readings?limit=100`

Последние N показаний в обратном хронологическом порядке.

```bash
curl -k https://localhost:8443/api/readings?limit=10
```

---

### `GET /api/pending`

Посмотреть, какие команды стоят в очереди (ещё не отправлены на устройство).

```bash
curl -k https://localhost:8443/api/pending
```

## Конфигурация

Файл [`config.py`](config.py):

| Параметр    | По умолчанию | Описание                                          |
|-------------|--------------|---------------------------------------------------|
| `HOST`      | `"0.0.0.0"`  | Адрес, на котором слушает сервер                  |
| `PORT`      | `8443`        | Порт HTTPS                                        |
| `CERT_FILE` | `"cert.pem"` | Путь к сертификату                                |
| `KEY_FILE`  | `"key.pem"`  | Путь к приватному ключу                           |
| `DB_FILE`   | `"cactus.db"` | Файл базы данных SQLite                          |
| `CERT_IPS`  | `["127.0.0.1"]` | IP-адреса в SAN сертификата (для браузера)   |

## Деплой на сервер с фиксированным IP

1. Скопируй файлы на сервер (например, через `scp` или `git`).

2. В `config.py` добавь IP сервера в `CERT_IPS`:
   ```python
   CERT_IPS = ["127.0.0.1", "1.2.3.4"]  # 1.2.3.4 — внешний IP сервера
   ```

3. Удали старый сертификат (если был), чтобы он сгенерировался заново:
   ```bash
   rm cert.pem key.pem
   ```

4. Запусти сервер. На Linux удобно через `systemd` или в `screen`/`tmux`:
   ```bash
   python server.py
   ```

5. Обнови `SERVER_URL` в `config.h` на адрес сервера и перепрошей M5Stick:
   ```c
   #define SERVER_URL "https://1.2.3.4:8443/api/cactus"
   ```

6. Если сервер за файрволом — открой порт 8443:
   ```bash
   # UFW (Ubuntu/Debian)
   ufw allow 8443/tcp
   ```
